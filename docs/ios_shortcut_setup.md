# iOS ショートカット設定ガイド

iPhoneの「ショートカット」アプリを使って、タスクメモからDaily Noteを作成するための設定手順です。

## 前提条件

- サーバーがインターネットからアクセス可能であること
- APIトークンを設定済みであること
- iPhoneに「ショートカット」アプリがインストールされていること

---

## ショートカット 1: テキスト入力でタスク送信

iPhoneでタスクをテキスト入力して送信するショートカットです。

### 設定手順

1. **ショートカット** アプリを開く
2. 右上の **+** をタップして新規ショートカットを作成
3. 以下のアクションを順番に追加:

#### アクション 1: テキストを入力
- 「テキストを入力を要求」を追加
- 質問: `今日のタスクを入力（改行区切り）`

#### アクション 2: テキストを分割
- 「テキストを分割」を追加
- 区切り文字: `改行`

#### アクション 3: 辞書を作成
- 「辞書」を追加
- キー `tasks` → 値: 分割されたテキスト（リスト型）
- キー `memo` → 値: 空文字列（任意）

#### アクション 4: URLの内容を取得
- 「URLの内容を取得」を追加
- URL: `https://YOUR_SERVER:8000/api/daily-note`
- 方法: `POST`
- ヘッダー:
  - `Authorization`: `Bearer YOUR_API_TOKEN`
  - `Content-Type`: `application/json`
- 本文: JSONとして辞書を指定

#### アクション 5: 通知を表示
- 「通知を表示」を追加
- タイトル: `Daily Note作成完了`
- 内容: URLの内容を取得の結果

### ショートカット名
- 名前: `Daily Note作成`
- アイコン: 任意（例: 📝）

## ショートカット 2: ファイルアップロードでタスク送信

メモ帳や他のアプリで書いたテキストファイルをアップロードするショートカットです。

### 設定手順

1. 新規ショートカットを作成
2. 以下のアクションを順番に追加:

#### アクション 1: ファイルを選択
- 「ファイルを選択」を追加

#### アクション 2: 日付をフォーマット
- 「日付をフォーマット」を追加
- 日付形式: `カスタム`
- フォーマット文字列: `yyyy-MM-dd`

#### アクション 3: URLの内容を取得
- 「URLの内容を取得」を追加
- URL: `https://YOUR_SERVER:8000/api/daily-note/upload`
- 方法: `POST`
- ヘッダー:
  - `Authorization`: `Bearer YOUR_API_TOKEN`
- 本文のタイプ: `フォーム`
- フォームフィールド:
  - `file`: 選択したファイル（ファイル型）
  - `target_date`: フォーマットした日付

#### アクション 4: 通知を表示
- 「通知を表示」を追加

---

## ショートカット 3: 共有シートから送信

他のアプリの「共有」メニューから直接テキストを送信するショートカットです。

### 設定手順

1. 新規ショートカットを作成
2. **ショートカットの詳細** → **共有シートに表示** を有効化
3. 入力の種類: `テキスト`
4. 以下のアクションを追加:

#### アクション 1: テキストを分割
- ショートカットの入力を改行で分割

#### アクション 2〜4: ショートカット1と同様

---

## 通知の設定（推奨: Pushover）

iPhoneにプッシュ通知を送るには **Pushover** が最も簡単です。

### Pushover 設定手順

1. [Pushover](https://pushover.net/) でアカウント作成
2. iPhoneに Pushover アプリをインストール
3. Web管理画面で Application を作成 → API Token を取得
4. `.env` に設定:
   ```
   DN_NOTIFICATION_METHOD=pushover
   DN_PUSHOVER_USER_KEY=your_user_key
   DN_PUSHOVER_API_TOKEN=your_api_token
   ```

### LINE Notify 設定手順

1. [LINE Notify](https://notify-bot.line.me/) にログイン
2. 「トークンを発行する」からトークンを取得
3. `.env` に設定:
   ```
   DN_NOTIFICATION_METHOD=line
   DN_LINE_NOTIFY_TOKEN=your_token
   ```

## ウィジェット / オートメーション

### ホーム画面ウィジェット
1. ショートカットをホーム画面に追加
2. ワンタップでDaily Note作成

### 毎朝の自動実行
1. 「ショートカット」→「オートメーション」
2. 「時刻」トリガーで毎朝 8:00 に実行
3. 前日のメモをiCloud Driveから読み込み → 自動送信

## トラブルシューティング

### 「接続できません」エラー
- サーバーが起動しているか確認
- URLが正しいか確認
- HTTPS が必要な場合はリバースプロキシ（nginx等）を設定

### 「認証エラー」
- Authorization ヘッダーが `Bearer YOUR_TOKEN` 形式になっているか確認
- トークンが `.env` の `DN_API_TOKEN` と一致するか確認

### ファイルアップロードが失敗する
- ファイルがUTF-8エンコーディングであることを確認
- ファイルサイズが大きすぎないか確認
