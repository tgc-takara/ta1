# 競合調査レポート(2026-08-10)

ひとつみ(旧仮称: TrackStack)の企画検討のため、日本・海外の習慣/記録アプリを調査した。
目的は (1)機能面の差別化ポイントの把握、(2)アプリ名を決めるための命名傾向の把握。

調査方法: Web検索 + App Store 公式ページ。価格・評価数値は原則として公式ページ記載の事実。
「不満点」「傾向」の多くは個人ブログ・note等の二次情報を含む。断定できない箇所は本文中に明記した。

---

## 1. 結論(先に要点)

1. **3領域(読書・筋トレ・勉強)を1つで記録する競合はほぼ存在しない**。唯一の近縁が「筋トレ勉強仕事記録アプリ」(2026年新規、レビュー数僅少)
2. **エクスポート機能は国内アプリの明確な空白地帯**。特に読書・勉強領域では公式エクスポートを持つアプリがほぼない
3. **ローカル完結・データ所有を打ち出すアプリは海外でも少数派**(Loop Habit Tracker / Nomie などOSS・ニッチ寄りのみ)
4. **日本の勉強・読書アプリはSNS/コミュニティ型が主流**。SNSを排除した設計(ビブリア)は「他人と比較しなくていい」と高く評価されている
5. **汎用ライフログは「何でも記録できる」だけでは続かない**(Gyroscopeが汎用ダッシュボードから月額$29のAIコーチングへ路線変更)。3領域に絞る設計は妥当

**Gyroscopeの事例**(重要): 2010年に「何でも繋いで可視化する」汎用ダッシュボードとして開始したが、
無料〜低価格帯では継続率が上がらず、月額$29の「AIコーチング+Health Score」という狭い垂直型へ転換した
(根拠は公式ブログの自己言及。第三者検証記事は未発見)。
→ 「何でも記録できる」こと自体は評価されにくく、**意思決定に接続されて初めて価値になる**。

## 3. 命名傾向の分析

### 3.1 日本市場: 説明的・検索最適化型が主流

| パターン | 実例 |
|---|---|
| 機能直球(日本語) | 読書メーター、筋トレカレンダー、勉強時間記録、集中、マッスルノート、読書管理ビブリア |
| 極端な検索最適化 | **筋トレ勉強仕事記録アプリ**、読書管理Readee、Bookmory 本棚 読書記録 読書管理 |
| カタカナ造語 | ブクログ(ブック+ログ)、バーンフィット、ツンドク、ネコノホンシツジ |
| 英語名 | Studyplus、StudyCast、Strong、Bookmory、Yomoo |
| 行動を促す語 | みんチャレ(みんなでチャレンジ) |

日本のアプリ名は**App Store検索対策(ASO)のために説明語を詰め込む**傾向が顕著。
「〇〇記録」「〇〇管理」を名前やサブタイトルに入れるのが定石。

### 3.2 海外市場: 抽象語・比喩語が主流

| パターン | 実例 |
|---|---|
| 直球機能型 | Habit Tracker、Toggl Track |
| 動詞・命令形 | Done、Streaks、Strides |
| 比喩型 | Forest、Habitica、Gyroscope、Trail |
| 造語型 | Habitify、Daylio、Nomie、Basmo、Bookly |
| 実在単語転用 | Exist、Reflect、Strong、Notion、Slack |
| 状態・感情語 | Way of Life、Bearable、Steady |
| 短縮語 | Jefit、Hevy |

上位アプリは**1〜2音節・7文字以内**が多く、発音しやすさと検索性が重視される。
「Habit Tracker」的な直球羅列名は上位に少ない。

### 3.3 本アプリへの含意

TrackStackは**個人利用専用でApp Store公開しない**ため、ASO(検索最適化)を考慮する必要がない。
つまり日本市場の「説明語を詰め込む」定石に従う理由はなく、
**海外型の短い抽象語・比喩語**(愛着が持てる名前)を選ぶのが合理的。

避けるべき名前: **Streaks / Strong / Forest / Done** など既存の有名アプリと衝突するもの
(個人利用でも、検索や会話で紛らわしい)。

## 4. 差別化ポイント(調査からの結論)

| # | 差別化軸 | 根拠 |
|---|---|---|
| 1 | **3領域の統合** | 読書・筋トレ・勉強を1つで記録する競合がほぼ存在しない。各アプリは単一カテゴリ特化 |
| 2 | **エクスポート(JSON/CSV/Obsidian Markdown)** | 読書メーター・Studyplus・StudyCast・みんチャレなど主要国内アプリに公式エクスポートがない。Habitifyは有料。Readee終了でニーズが顕在化 |
| 3 | **ローカル完結・SNSなし** | 国内の勉強/読書アプリはSNS型が主流。SNSを排したビブリアは「他人と比較しなくていい」と高評価。海外でもローカル完結はOSSニッチのみ |
| 4 | **横断タイマー** | 読書記録でタイマーを持つのはBookmoryのみ。3領域を1つのタイマーで計測できるものは見当たらない |
| 5 | **カテゴリ横断の相関** | Exist.ioが「相関分析」で支持されている。「筋トレした日は勉強時間が長い」等はM4以降の拡張余地 |

一方で**避けるべき方向**:
- 汎用化しすぎない(Gyroscopeの失敗事例)。3領域に絞る現設計を維持する
- ゲーミフィケーションの過剰(Habiticaの「ゲーム性がノイズ」評)
